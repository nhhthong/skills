# Credits

This plugin builds on two MIT-licensed projects. Both licenses are reproduced at the end of this file.

## Matt Pocock: [mattpocock/skills](https://github.com/mattpocock/skills)

The base of this repo: the skill layout, the `.work/` record, and the first versions of the clarify, plan, implement, test, debug, review and design skills.

## Lauren Tan: [pstack](https://github.com/cursor/plugins/tree/main/pstack)

Ideas adapted, with the pstack skill each came from named in the file that uses it:

- Proof levels, the "able to fail" bar and the `check`, `light` and `full` tiers: `test-plan/PROOF.md`.
- Two-way planning: `plan-tickets/TWO-WAY.md`.
- `review-impact`, the Adversary review axis, `explore-why`, `explore-how`, `test-benchmark` and `setup-verify`.
- Commit sequencing, red flags and design-it-twice: `implement-ticket/SEQUENCE.md`, `design-modules`.
